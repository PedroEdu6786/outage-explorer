- This file keeps the refresh worker running and maintains its ownership of an active refresh. It contains two classes: **`SupervisedRefreshProcess` — the waiting loop** - Calls the injected `tick()` function to check for and execute queued work. - Waits one second by default before checking again. - Continues running after database-access or stale-ownership errors so a later tick can reconcile the state. - Stops on `SIGTERM` or Ctrl+C. - Its `close()` method stops the loop and calls the injected cleanup function once. **`RenewableRefreshLease` — the ownership heartbeat** - While a refresh runs, starts a background thread that renews its database lease every 10 seconds by default. - Each renewal extends ownership for 60 seconds by default. - Records heartbeat failures; `check()` raises them so the refresh can respond. - Stops and joins the heartbeat thread when the operation finishes. The actual data fetching, processing, and publishing happen elsewhere. This file provides the **polling loop, shutdown handling, and lease renewal** around that work.
