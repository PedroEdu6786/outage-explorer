# Implementation plan

1. Preserve the existing sanitized facility/generator snapshot bytes and hashes
   in separate tracked bundles with metadata, source profile and capacity research.
   Document bounded contract v1 from the actual nine/ten-field samples and facets.
2. Extract national's pure observation policies into a shared domain module with
   explicit national/facility/generator grains. Preserve the national interface;
   extend observation equality and selection with entity identifiers and name.
3. Reuse application evidence/report ports and orchestration, adding entity/date
   coverage and response-total evidence. Parameterize local evidence validation
   by dataset and render detail identifiers, counts, coverage and limits.
4. Add facility/generator composition functions and thin CLI startup wrappers,
   extending the exact AST allowlist and negative fixtures. Preserve national's
   entry point, defaults and report format.
5. Verify synthetic edge cases and both real baselines; run the full quality gates,
   execute both CLI reports and record measured outcomes and limitations.

No new dependencies or infrastructure. Coverage is the cross-product of 30 dates
and the bundle's observed identifiable entities, not an asserted active fleet.
Use indexed exclusions for detail coverage rather than rescanning all source rows
for every entity/date. Report schema remains v1 per dataset, with explicit dataset
identity for the new detail reports.
