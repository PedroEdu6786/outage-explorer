## Implementation notes (October 6, 2026)
- `PostgresqlResourcePublicationStore` and the retained manifest store share one fenced transaction base; each rejects the other layout before any state change. Migration 0004 adds the database-validated descriptor constraint, with a downgrade that refuses once resource rows exist.
- `VerifiedResourceCache` pins one exact object per dataset (one GET, no manifest/HEAD/listing), verifies bytes, SHA-256, exact resource schema, rows and coverage, and shares identical verified bytes across generations. `open_restricted` projects public columns; the public-only layout is accepted by name only until phase 4 removes it.
- New suites: `tests/integration/test_resource_readers.py`, `tests/integration/test_resource_browsing.py`, plus resource cases in `test_data_api_postgresql.py` and `test_query_worker_transport.py`. The pre-existing manifest-layout suites still pass unchanged.
