FRONTEND 01 · All frontend pages

Atomic Design

UI building blocks

Atomic Design organizes an interface into five levels: small elements, useful groups, complete sections, page layouts and finished screens.

  • Explain what each of the five levels represents.
  • Use a button, a labeled field, a table and Overview as familiar examples.
  • Show how reusable pieces become a complete screen.
